## 2. Performance 任务页面重构

### 2.1 三行布局

| 行 | 内容 | 说明 |
| --- | --- | --- |
| 第一行 | Perf + Cases + Console | 三面板各占 1/3 宽度，等高对齐 |
| 第二行 | Realtime Data | 占整行 |
| 第三行 | Statistics | 占整行 |

- 页面整体改为 `overflow: auto`，三行垂直排列
- 第一行三面板 `flex: 1 1 0` 严格等宽
- Perf 面板内容决定高度（`flex: 0 1 auto`，不滚动）
- Cases 与 Console 面板内容超出时各自滑动（`flex: 1; overflow: auto`）

### 2.2 Perf 面板

| 需求 | 实现 |
| --- | --- |
| 标题左侧：`Perf \| 模型名称` | `title-text` + `panel-title-model`，14px 600 深色（标题样式） |
| 标题右侧：Progress / Elapsed / Perf Status | `meta-text` 12px 灰色，状态高亮颜色保持 |
| 内容第一行：模型 + 模型名称 | `info-row` 两端对齐 |
| 内容第二行：Framework 值不加边框 | 移除 `a-tag`，纯文本 |
| 详情值字体样式一致 | 所有 `info-value` 统一 12px 400 深色 |
| Service URL 字体一致 | 移除 `mono-url` 等宽类，统一为 `info-value` |
| footer 右侧操作按钮 | Start / Stop / Close |

### 2.3 Cases 面板（新增）

- 独立面板显示并发 case 列表（1K1K 等 label + 输入/输出长度 + 各并发进度 tag）
- 有 Title（"Cases"）和 footer（空，占位保持等高）
- 内容超出时竖向滑动
- 空数据显示 `t('noData')` 提示

### 2.4 Console 面板

- 白底黑字（`background: #fff; color: #000`）
- 内容更新时始终滚动到底部，确保最新数据可见
- 新增空 footer 保持与 Perf / Cases 等高

### 2.5 i18n 新增

| 键 | 中文 | 英文 |
| --- | --- | --- |
| `casesPanelTitle` | Cases | Cases |
| `statistics` | 统计图 | Statistics |

## 3. Realtime Data 表格重构

### 3.1 后端 parser 扩展 ([parser.py](file:///root/benchscope/benchscope/parser.py))

新增解析以下字段（vLLM + SGLang 双格式）：

| 字段 | 来源标签 |
| --- | --- |
| `successful_requests` | `Successful requests:` |
| `failed_requests` | `Failed requests:` |
| `benchmark_duration` | `Benchmark duration (s):` / `Duration:` |
| `total_input_tokens` | `Total input tokens:` |
| `total_generated_tokens` | `Total generated tokens:` |
| `peak_concurrent` | `Peak concurrent requests:` |
| `req_per_s` | `Request throughput (req/s):` |
| `ttft_median` | `Median TTFT (ms):` |
| `tpot_median` | `Median TPOT (ms):` |
| `itl_median` | `Median ITL (ms):` |

- 新增 `kind="scalar"` 类型（不带后缀，如 `successful_requests`）
- median 缺失时回退 mean

### 3.2 API 序列化扩展 ([api_logs.py](file:///root/benchscope/benchscope/server/api_logs.py))

`_to_merged_rows` 新增字段透传到前端：`successful_requests` / `failed_requests` / `benchmark_duration` / `total_input_tokens` / `total_generated_tokens` / `request_throughput` / `peak_concurrent` / `ttft_median` / `tpot_median` / `itl_median`

### 3.3 表格列定义 ([MetricsTable.vue](file:///root/benchscope/web/src/components/MetricsTable.vue))

**列分组与默认显示**：

| 分组 | 默认显示列 | 可选显示列 |
| --- | --- | --- |
| 任务相关 | Case、Requests、Concurrency、Successful、Status | Successful requests、Failed requests、Benchmark duration (s)、Total input tokens、Total generated tokens |
| 吞吐 | Output token throughput、Peak output token throughput、Total token throughput | Request throughput (req/s)、Peak concurrent requests |
| TTFT | Mean TTFT、Median TTFT、P99 TTFT | - |
| TPOT | Mean TPOT、Median TPOT、P99 TPOT | - |
| ITL | - | Mean ITL、Median ITL、P99 ITL |

**列设置**：右上角下拉菜单，按分组勾选切换显示

### 3.4 表格样式

| 需求 | 实现 |
| --- | --- |
| 紧凑显示 | 表头 `padding: 2px 4px`，单元体 `1px 4px`，字号 12px |
| 默认列单行不换行 | `col-default` className，`white-space: nowrap` |
| 可选列可换行 | `col-optional` className，`white-space: normal` |
| 表头可换行 | `white-space: normal` |
| 最大 16 行 | `maxRows: 16`，超出竖向滚动 |
| Status 列固定右侧 | `fixed: 'right'`，Success + Best 单行 `inline-flex nowrap` |

### 3.5 行高亮规则

| 规则 | 实现 |
| --- | --- |
| 仅 Best 行高亮绿色 | `row-best` → `background: #d9f7be` |
| 其他行默认灰底黑字 | `background: #fafafa; color: #000` |
| Best 更新时原 Best 恢复默认 | `record.best` 标记驱动，由 store `annotatedRows` 重新计算 |
| 移除 near-threshold / error 高亮 | `rowClass` 仅返回 `row-best` 或空 |

### 3.6 Concurrency 列智能显示

| request_rate | 显示 |
| --- | --- |
| `inf` | `Inf` |
| `follow` | 同 Requests 列 |
| 其他 | `metrics.concurrency`，缺失回退 `record.concurrency` |

### 3.7 Successful 列

- 显示 `Failed/Successful` 百分比，保留 2 位小数（如 `100.00%`）
- 无数据时显示 `-`，error 时显示 `0%`

## 4. Statistics 统计图重构 ([MetricsCharts.vue](file:///root/benchscope/web/src/components/MetricsCharts.vue))

### 4.1 面板布局

- 面板标题改为「统计图 / Statistics」
- **4 列 × 3 行** 共 12 张图：

| 列 | 指标组 | y 轴单位 | 子图 |
| --- | --- | --- | --- |
| 1 | Throughput | tok/s | Output token throughput、Peak output token throughput、Total token throughput |
| 2 | Time to First Token | ms | Mean TTFT、Median TTFT、P99 TTFT |
| 3 | Time per Output Token | ms | Mean TPOT、Median TPOT、P99 TPOT |
| 4 | Inter-token Latency | ms | Mean ITL、Median ITL、P99 ITL |

- 每张图 160px 高
- 每列顶部有列标题（指标组名称 + 下边框分隔）
- 每张图上方有子标题（具体指标名）

### 4.2 默认显示网格

| 需求 | 实现 |
| --- | --- |
| 默认显示网格 | `xAxis.splitLine.show: true`、`yAxis.splitLine.show: true`，虚线 `#f0f0f0` |
| 无数据也显示网格 | `hasData` 判断，无数据时 `scale: false`，`min: 0, max: 100` 固定范围 |
| 强制轴渲染 | 无数据时添加空 series `[{ type: 'line', data: [], animation: false }]` |

### 4.3 跨图联动

- 保留 `echarts.connect('perf-charts')` 联动
- 所有 12 张图同 group，hover 时 tooltip / axisPointer 同步

### 4.4 坐标轴

- x 轴：请求数（record.concurrency），category 类型
- y 轴：对应单位（tok/s 或 ms），有数据时 `scale: true` 自适应
